to each (already connected, hosted MCP, API key, CLI, skill, `llms.txt`) and a connection cheat sheet. Sessions go to the category, take
rank 1, and move down the list only if it cannot do the job; they do not re-research tools that have a category. The 244 links in categories 1 to 23 were checked on
2026-11-21 (227 answered, 17 are auth or bot-blocked pages that exist, 0 dead); the Awwwards links in category 24 were saved the same day and not checked. Rank basis and the line format are at the top of that file.
Add new tools there under the right category with a rank and a connect note, and add a row here only when a new kind of reference appears.
